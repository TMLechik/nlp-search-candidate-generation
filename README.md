# Search Candidate Generation

Генерация до 50 объявлений для каждого поискового запроса. Код, эксперименты и подготовка ответа находятся в [research.ipynb](research.ipynb).

## Решение

- **Dense:** [Multilingual E5-small](https://huggingface.co/intfloat/multilingual-e5-small) без дообучения. Запрос - `search_query`, объявление - заголовок и параметры. Лимит 64 токена, поиск по косинусному сходству на GPU.
- **BM25:** поиск по заголовкам, `k1=1.5`, `b=0.75`.
- **RRF:** объединение top-50 двух методов с весами dense **0.55**, BM25 **0.45** и константой **60**. На выходе 50 уникальных кандидатов.

Используются Sentence Transformers, PyTorch, scikit-learn, NumPy, SciPy и pandas. BM25 и RRF реализованы в блокноте.

Для BM25 оставлен заголовок: добавление параметров снизило Recall@50 с 0.15146 до 0.14370. Для dense выбраны заголовок и параметры: добавление описания с увеличением лимита до 256 токенов снизило Recall@50 с 0.18362 до 0.17776.

## Валидация и результаты

20% уникальных нормализованных текстов запросов выделены в validation (`SEED=42`). Одинаковые формулировки не пересекаются между частями. Recall@50 усредняется по полным поисковым контекстам; корпус содержит 344 825 уникальных объявлений из `train`.

| Метод | Текст объявления | Recall@50 |
|---|---|---:|
| Word TF-IDF | title | 0.14345 |
| BM25 | title | 0.15146 |
| E5-small | title + params, 64 токена | 0.18362 |
| E5-small | title + params + description, 256 токенов | 0.17776 |
| RRF 0.50 / 0.50 | Dense + BM25 | 0.18457 |
| RRF 0.55 / 0.45 | Dense + BM25 | 0.18610 |

Это локальные результаты. Веса RRF подобраны на той же validation-выборке. Полная таблица экспериментов приведена в блокноте; Character TF-IDF остановлен без оценки качества из-за времени поиска.

## Обнаруженные проблемы

Word TF-IDF давал нулевой вектор для 0.30% validation-запросов: их токены отсутствовали в словаре, поэтому метод не находил кандидатов. Character TF-IDF устранил нулевые векторы, но поиск был остановлен из-за времени выполнения.

В экспериментах добавление полей снижало качество: параметров для BM25 и описания для dense. Эти варианты исключены из финального решения.

## Запуск

1. Нужны Python 3.12 и NVIDIA GPU с CUDA. Установите PyTorch с поддержкой CUDA, затем зависимости:
```bash
python -m pip install numpy==2.4.1 pandas==3.0.0 scipy==1.17.0 scikit-learn==1.8.0 matplotlib==3.11.1 pyarrow==23.0.1 sentence-transformers==6.1.0 transformers==5.8.0 tqdm==4.67.1 Jinja2==3.1.6 ipykernel==7.1.0 jupyterlab==4.5.6
```

2. Поместите `train.parquet`, `benchmark_queries.parquet` и `benchmark_items.parquet` в папку `data/`.  
3. Откройте research.ipynb и выполните ячейки последовательно сверху вниз.

Веса E5 загружаются при первом запуске.  
Промежуточные файлы создаются в `artifacts/dense/`;  
Данные и артефакты исключены из Git.

## Результат

`answer.csv`: UTF-8, разделитель-запятая, без индекса. Колонки `query_id` и `answer`, где `answer` содержит 50 `item_id` через пробел. Файл содержит 2 452 запроса; блокнот проверяет отсутствие повторов и наличие всех кандидатов в `benchmark_items`.
